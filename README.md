# Troop 710 Website

A responsive public-facing website for Scouting America Troop 710 in **Hacienda Heights, California**.

## Publishing with GitHub Pages

This is a static website: no build commands, dependencies, or passwords required.

1. Go to the repository's **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose **main** and **/(root)**, then **Save**.
4. After GitHub Pages deploys, the expected public URL is: **https://willn0tbill.github.io/Troop710/**.

The site is committed, but GitHub Pages must be enabled separately in GitHub settings before that address works.

## Features

- Modern hero and editorial design with an outdoors aesthetic
- About, experiences, youth leadership, service, and joining sections
- FAQ and current-information links to TroopWebHost
- Mobile-friendly navigation, accessible semantic HTML, reduced-motion support
- No frameworks, tracking scripts, back-end services, or contact-form data collection

## Verified public information

The public [TroopWebHost directory](https://www.troopwebhost.org/) lists **Troop 710 — Hacienda Heights, California**.

Meeting time, meeting address, specific troop calendar, names of leaders, contact addresses, dues, and current events **have not been verified**. The site deliberately avoids inventing them. Until a troop-controlled direct TroopWebHost page is confirmed, links go to the public directory.

## Images and permissions

The website uses illustrative outdoor images hosted by Unsplash; **they are not photos of Troop 710 members or events**. Replace them with approved troop-owned imagery when available. Obtain troop and parent/guardian consent before posting identifiable youth photos or personal information.

An authorized adult troop leader should review public site copy, branding, registration process, imagery, and privacy before launching it as an official troop website.

## Editing

All page code (HTML, CSS, and a tiny mobile-menu script) is contained in **index.html**. Update the copy directly there. For verified troop contact details, meeting times, and a direct TroopWebHost link, search for "https://www.troopwebhost.org/" in that file and replace the relevant links.
